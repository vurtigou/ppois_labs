## Возможности классов

### Set (Множество)
- Элементом может быть другое множество.
- Проверка на пустоту и определение мощности множества.
- Добавление и удаление элементов.
- Проверка принадлежности элемента (`[]`).
- Сравнение множеств на равенство (`==`, `!=`).
- Объединение (`+`, `+=`), пересечение (`*`, `*=`) и разность (`-`, `-=`).
- Построение булеана (множества всех подмножеств).
- Формирование множества из строки и потоковый ввод/вывод (`<<`, `>>`).

### Polynomial (Многочлен от одной переменной)
- Получение значений коэффициентов (`[]`).
- Вычисление значения многочлена для заданного аргумента (операция вызова объекта как функции — `operator()` в С++.
- Сложение двух многочленов (`+`, `+=`).
- Вычитание двух многочленов (`-`, `-=`).
- Умножение двух многочленов (`*`, `*=`).
- Деление двух многочленов (`/`, `/=`).
- Сравнение двух многочленов на равенство (`==`, `!=`).
- Потоковый ввод/вывод в математическом формате (`<<`, `>>`).

## Сборка из консоли (без IDE)

Проект собирается с использованием **CMake**. Нужно убедиться, что установлены CMake (≥ 3.10) и компилятор с поддержкой C++17. 

### Linux / macOS / Windows 
```bash
cmake -B build
cmake --build build
```

## Запуск 

После успешной сборки в папке `build` появятся исполняемые файлы. Интерфейс полностью отделен от логики предметной области.

**Запуск консольного меню (CLI) для Множества:**
- Windows: `.\build\Debug\set_app.exe`
- Linux/macOS: `./build/set_app`

**Запуск консольного меню (CLI) для Многочлена:**
- Windows: `.\build\Debug\poly_app.exe`
- Linux/macOS: `./build/poly_app`


## Тестирование
Проект покрыт unit-тестами (покрытие > 90%). Тесты не используют сторонние фреймворки и запускаются напрямую из консоли.

**Запуск тестов**
- Windows: 
```cmd
.\build\Debug\set_tests.exe
.\build\Debug\poly_tests.exe
```
- Linux/macOS: 
```bash
./build/set_tests
./build/poly_tests
```

**Запуск тестов**
Для проверки покрытия используется `lcov` (требуется компиляция с флагом `-DENABLE_COVERAGE=ON`):
```bash
cmake -B build -DENABLE_COVERAGE=ON
cmake --build build
cd build
lcov --capture --directory . --output-file coverage.info
lcov --remove coverage.info '/usr/*' --output-file coverage.info
lcov --list coverage.info
```

## CI/CD Pipeline
При каждом пуше или Pull Request автоматически запускается GitHub Actions workflow (`.github/workflows/ci.yml`), который выполняет:
1. Сборку проекта с помощью CMake (с флагом покрытия).
2. Запуск всех unit-тестов.
3. Проверку покрытия кода (отчет `lcov` выводится в лог).
4. Статический анализ кода (линтер `cpplint`).
5. Публикацию исполняемых артефактов (`set_app` и `poly_app`) в раздел Releases при пуше тега версии (например, `v1.0`).
